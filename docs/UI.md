# Interface

The public interface is a compact Mac menu bar popover. It follows system light/dark
appearance and reduced-motion preferences. Full session names wrap rather than requiring
selection. Lifecycle is written in words; color and expression supplement the text.

Working portraits are colorful with a steady halo and gentle sway. Waiting retains a
questioning expression without motion. Quiet, finished, queued, stale, and disconnected
sessions have distinct text and muted presentation. Reduced motion removes the sway.
Session colors stay stable while visible, including multiple sessions from one agent.

Opening a session does not imply work. A hidden quiet portrait stays hidden through
resume and returns when a real prompt/tool event indicates work. Open actions only target
verified local hosts; unavailable or partial focus has a plain-language explanation.

Controls: Calm, audio on/off, volume, Open at login, and Quit. Errors say what happened
and what to do. No console, timeline, replay picker, sandbox, or Sound Lab ships publicly.
The hidden renderer exists solely to own browser audio for the Mac host.
